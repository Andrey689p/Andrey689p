## 🧠 About Me

Sou desenvolvedor Full-Stack com foco em construção de sistemas organizados, escaláveis e orientados a regras de negócio.

Atualmente curso Análise e Desenvolvimento de Sistemas e atuo com tecnologias como **Angular, TypeScript, Node.js e APIs REST**, desenvolvendo aplicações completas do frontend ao backend.
